# Política de Desarrollo y Contribución — AeroGym

**AeroGym** es un proyecto privado y de desarrollo exclusivo mantenido por **Xavi de Solutech**.

---

## 🔒 Contribuciones Cerradas

- **No se aceptan Pull Requests externas**: El repositorio está cerrado a contribuciones públicas.
- **Uso de la Aplicación**: Los usuarios pueden acceder a la versión oficial desplegada a través de **GitHub Pages**.
- **Reporte de Problemas**: Si encuentras algún error o tienes sugerencias sobre la aplicación web en producción, puedes comunicarlo al equipo de desarrollo de Solutech.

---

## 🚀 Despliegue Automatizado

El despliegue de la versión de producción a GitHub Pages se gestiona automáticamente mediante **GitHub Actions** en `.github/workflows/deploy.yml` al realizar cambios en la rama principal.
